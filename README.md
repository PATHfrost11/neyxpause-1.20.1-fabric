# Custom ESC Menu  Tired of the plain vanilla pause screen? **Custom ESC Menu** replaces it with a sleek, animated one: smooth slide-in buttons, hover effects, and a compact player card, all drawn in code, so there are no extra textures to download.  ## Features  - **Animated buttons**: slide in one by one when you open the menu, with a highlight sweep and a small text shift on hover - **Clean layout**: a dark gradient background, a fading left-hand panel, and a subtle shimmer effect - **Player card**: your skin head, name, server address (or "Singleplayer"), and current coordinates - **Dimension tag**: shows the dimension you're in at the top right - **Fully functional**: Back to Game, Advancements, Statistics, Options, Open to LAN (singleplayer), and Save and Quit / Disconnect all behave exactly like vanilla - **Client-side only**: install it on your client and it works on any server, vanilla or modded, with no server-side setup  ## Requirements  - Minecraft **1.20.1** - [Fabric Loader](https://fabricmc.net/) 0.15.0 or newer - [Fabric API](https://modrinth.com/mod/fabric-api)  ## Installation  1. Install Fabric Loader for Minecraft 1.20.1 2. Drop **Fabric API** and **Custom ESC Menu** into your `mods` folder 3. Launch the game and press `Esc`  ## FAQ  **Does it work on servers?** Yes. It only changes the pause screen on your own client, so you don't need it on the server.  **Is it compatible with other mods?** It replaces the vanilla pause screen, so mods that also replace or heavily modify that screen may conflict. If you find one, please report it on the issue tracker.  **Does it need a resource pack?** No. Everything is drawn in code.  **Can I change the colors?** Not through an in-game config yet. The accent color and layout values are constants in the source code, so you can change them there and rebuild.  **What about F3 + Esc?** It opens the full menu instead of the reduced one vanilla shows.  ## Links  - Source code and issues: _add your GitHub link here_  Found a bug or have an idea?
